# **App Name**: Mana Counter

## Core Features:

- Player Life Tracking: Allow users to input and track the life totals for multiple players in a Magic: The Gathering game. Implement an increase/decrease life total using buttons
- Dice Rolling: Provide a dice rolling feature for various dice types (d4, d6, d8, d10, d12, d20, d100) and allow users to roll multiple dice at once.
- Commander Damage Tracking: Track commander damage dealt to each player, and show warnings when players reach zero life.
- Game History: Keep track of each game played and make the logs easily accessible to the users
- Name generation: A tool that will recommend a gamertag using LLM based on your name.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) evoking a mystical feel reminiscent of Magic: The Gathering.
- Background color: Light lavender (#F3E5F5), a very low saturation shade of the primary, providing a soft backdrop.
- Accent color: Vibrant pink (#E91E63), an analogous color to purple, used for interactive elements and highlights.
- Font: 'Alegreya', a serif with an elegant, intellectual feel suitable for headlines and body text.
- Use custom icons representing life counters, dice, and Magic: The Gathering symbols.
- Intuitive layout with life counters prominently displayed for each player.
- Subtle animations for dice rolls and life total adjustments.
